# CRISIS ENGINE v3.0

Лёгкий монитор стресса: **сборщик на Python (stdlib) → data/*.json → статичный index.html**.
Браузер ничего не качает с внешних API, CORS-прокси и кэша в localStorage больше нет.

```
engine.py    загрузка источников + расчёт (одна функция compute(asof) на «сегодня», историю и бэктест)
collect.py   пишет data/latest.json и data/history.json
backtest.py  пишет BACKTEST.md (2008, 2011, 2018, 2020, 2022, 2024 + 2025 как контроль)
index.html   интерфейс (без библиотек, без веб-шрифтов)
.github/workflows/update.yml   запуск по расписанию в будни, 2 раза в день
```

## Запуск
1. Залить папку в GitHub-репозиторий → Settings → Pages → Deploy from branch (`main`, `/root`).
2. Actions → *update-data* → **Run workflow** (первый запуск; дальше по расписанию).
3. Локально: `python collect.py && python -m http.server` → http://localhost:8000
4. Бэктест: `python backtest.py` (≈ минута, нужен интернет).

Ключи API не нужны. Если часть источников недоступна, показатель получает статус «нет данных»,
а при недостаточном покрытии итоговый индекс и рекомендации **не выдаются**.

## Как это устроено
- **Net Liquidity** = WALCL − TGA − ON RRP (WALCL, TGA — млн $; ON RRP — млрд $, поэтому ×1000); изменения за 1/4/12 нед.
- **M2**: факт за 3 мес., годовой темп 3 мес. и YoY — три отдельные величины.
- Каждый показатель → стресс 0–100 как **перцентиль относительно собственной истории** (до 15 лет), а не фиксированный порог;
  фиксированные пороги остаются только как «полы» там, где они общепризнаны (Sahm ≥ 0.5, GDPNow < 0, NFCI > 0).
- Четыре блока: Liquidity, Credit, Market, Macro (веса 25/30/25/20). Надбавка +5 за ≥ 3 подтверждённых блока (≥ 60) и +5 за ускорение (≥ +10 за 4 нед.).
- **Свежесть** считается по календарю релизов: допуск = период ряда + типичный лаг + запас. Месячный ряд 40-дневной давности не «устарел».
- **Цикл** (рост / замедление / риск рецессии / рецессия / восстановление) и **режим рынка** (Risk-on … капитуляция) — независимые состояния;
  рецессия — только при ≥ 3 из 5 макро-подтверждений.
- История = пересчёт по данным, опубликованным к каждой дате (не повторяющиеся значения из кэша).

## Известные ограничения
- Даты публикации — оценка (наблюдение + лаг), не vintage-даты ALFRED; ревизии не учтены.
- ISM лицензирован → Philly Fed как прокси. Ширина S&P — прокси RSP/SPY, IWM/QQQ.
- ETF-потоки и ликвидации криптоопционов бесплатного первоисточника не имеют: показаны как «нет источника».
- Идентификаторы рядов (FRED/Yahoo/DefiLlama/OKX) проверены по памяти без доступа к сети: при первом запуске
  `collect.py` печатает, какие именно не загрузились. История ICE BofA на FRED может быть ограничена лицензией —
  тогда для кредита используются Baa−10Y, NFCI, SLOOS.
- Вероятности в процентах не показываются: калибровка не проводилась.
